# hilmimokhsen.my.id

Website resmi **Hilmi Mokhsen** (Hilmiyatillah Mokhsen, S.Sos., M.I.Kom.) — influencer, content creator, pembicara & MC NTT dari Kupang.

Situs statis satu halaman (HTML + CSS + sedikit JavaScript, tanpa build step). Bisa di-hosting di Cloudflare Pages, Netlify, Vercel, atau GitHub Pages langsung dari branch `main`.

- **Panduan setup Google Search Console, Bing, IndexNow, Wikidata & perawatan:** [docs/PANDUAN-SETUP.md](docs/PANDUAN-SETUP.md)
- **Preview lokal:** `python3 -m http.server 4321`, lalu buka <http://localhost:4321>
